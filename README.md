# Kencana Graha - Mini Website Konstruksi, Interior & Eksterior

Mini website profil bisnis profesional untuk **Kencana Graha**, penyedia layanan konstruksi, arsitektur, dan desain interior/eksterior terpercaya.

![Preview Website](public/og-image.png)

---

## 🌟 Fitur Utama

- **Hero Section Elegan**: Dilengkapi profil resmi, tombol WhatsApp langsung, dan statistik reputasi.
- **Katalog Portofolio & Lightbox**: Galeri karya proyek dengan filter kategori (*Eksterior* & *Interior*) serta modal lightbox resolusi penuh.
- **Layanan Terpadu & Riwayat Perjalanan**: Menampilkan spesialisasi pengerjaan dan timeline perkembangan perusahaan.
- **Paket Layanan & Biaya**: Estimasi biaya transparan mulai dari paket desain hingga bangun premium.
- **FAQ Accordion Interaktif**: Jawaban praktis untuk pertanyaan umum seputar biaya, durasi, dan garansi.
- **Form Konsultasi WhatsApp Otomatis**: Pengunjung dapat mengisi detail rencana pembangunan dan langsung mengirim pesan terformat rapi ke WhatsApp bisnis.
- **Sticky CTA & Share Modal**: Tombol mengambang untuk kemudahan konsultasi cepat serta opsi bagikan tautan.
- **SEO & Social Share Ready**: Terintegrasi lengkap dengan Open Graph meta tags (`og:image`, `og:title`, `og:description`), Twitter Card, dan favicon resmi.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Font**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)

## 🚀 Panduan Menjalankan di Komputer Lokal

### 1. Prasyarat
Pastikan sudah menginstal [Node.js](https://nodejs.org/) (versi 18+ disarankan).

### 2. Clone Repository
```bash
git clone https://github.com/solusilokal/Kencana-Graha.git
cd Kencana-Graha
```

### 3. Install Dependensi
```bash
npm install
```

### 4. Jalankan Server Pengembangan
```bash
npm run dev
```
Buka browser di `http://localhost:5173`.

### 5. Build untuk Produksi
```bash
npm run build
```
